# Portfolio · Tahiel Cassata

Analista en Sistemas en formación, orientado a soporte técnico y automatización con IA aplicada.

**Ver online:** https://tahielcassata.github.io/portfolio/

Incluye una página por proyecto con un demo animado de su flujo:

- [ReservaFácil](https://github.com/tahielcassata/reservafacil): sistema de turnos con recordatorios por WhatsApp.
- [Bot de historial de arreglos](https://github.com/tahielcassata/bot-historial-arreglos): bot de Telegram para una bicicletería.
- [Control de caja diario](https://github.com/tahielcassata/control-de-caja-diario): cobros desde una tablet con cierre del día automático, modo sin internet y administración con PIN, para negocios de servicios.

Hecho con HTML, CSS y JavaScript, publicado con GitHub Pages.
